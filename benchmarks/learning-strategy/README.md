The experiment compares a fixed versus evolving proposer crossed with incumbent versus population parent selection. Actor instructions and proposer instructions are separate bounded text fields; neither can change a verifier, tool permission, budget, or executable source. Every selected policy is evaluated through actual model/tool actions and an independent outcome oracle. The archive preserves losing branches without activating them.

The finite discovery environment exposes an unknown deployed numerical or sequence transformation. All candidate function definitions and allowed probes are public. The actor chooses up to three probes and then submits an implementation. A separate oracle checks complete behavior on a fixed challenge suite. This is a synthetic tool-contract experiment, not a real application benchmark or user trial. A deterministic information-gain control uses the same public hypotheses and observable tool responses; its success establishes that the information is sufficient and is an important cheaper alternative.

The pilot checks headroom before the main study. The initial actor already has explicit hypothesis tracking and diagnostic guidance. The main study uses two seeded task cohorts and three generations in each of four arms. Model sampling is not seeded. Every selected actor and its unchanged starting actor are frozen before evaluation on the same final panel; when selection keeps the initial strategy, its result is reused. These are feasibility experiments, not powered tests of recursive improvement. The transfer experiment resets the actor and transfers only the proposer to recipients in another domain and under version drift. Source and recipients have distinct databases; signed envelopes are delivered in-process, not through a live mesh. Source qualification is not imported. A one-generation recipient comparison holds each starting proposer fixed for the one child it generates.

Before the main collection, development and held-out panels were amended to use disjoint hypothesis IDs within each cohort. Equivalent behavior can still occur between different IDs, and both panels come from the same finite family. Pilot v3 did not enforce this semantic split and is excluded from main efficacy estimates. A deterministic control is reported alongside all final panels.

Paid collection uses the existing `ANTHROPIC_API_KEY` and pinned `claude-sonnet-4-6`. Legacy collectors retain their historical $10/$15 ceilings. The expanded collector records the user's broader spending authorization and uses finite per-lane engineering circuit breakers, while tracking all earlier exposure and unresolved reservations. Credentials never enter results. An exclusive collector lock prevents concurrent studies; at most three provider requests run concurrently within a study. One store's operations are serialized. Failed or interrupted requests do not silently retry. Read a collector's completion status before treating a run as fully observed.

Each run freezes the protocol, source snapshots, provider prices and runtime version before provider calls. Snapshots are immutable study evidence; do not format or edit their source copies. Every provider request has a durable intent, raw synthetic response, usage receipt and model identity. Frozen pricing is a list-price estimate, not an invoice. Each node records its own proposal and evaluation costs; full source discovery is additionally allocated to deployments that depend on transferred strategies. Physical spend and deployment allocation are distinct.

`analyze.mjs` checks the frozen protocol, source copies, complete assigned arms, final panel sizes and node/provider cost reconciliation. `audit.mjs` is a post-collection diagnostic: it recomputes charges from raw provider usage, checks prompt hashes and reports action failures versus submissions inconsistent with observed probes. These diagnostic categories were not preregistered efficacy endpoints and never feed candidate selection.
